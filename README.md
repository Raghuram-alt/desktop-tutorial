# BYD USA homepage

Responsive automotive brand concept built with vanilla JavaScript and Vite.

## Run

Requires Node.js 20.19+ or 22.12+.

```sh
npm ci
npm run dev -- --port 5173
```

## Production build

```sh
npm run build
npm run preview
```

Features: two-model hero controls, mobile navigation, model and company links, responsive mission/contact sections, native form validation, and an accessible contact dialog. The form does not transmit or store personal information; its dialog links to the official BYD contact page. A backend integration is needed for direct submissions.

Visual reference: https://gitreverse.com/designs/byd-com
Vehicle imagery and logo sourced from BYD's public website. Models are presented as global brand showcases; availability varies by market.
